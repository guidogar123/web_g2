## Spacing Scale

Declared values (8-point scale, multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon internal padding, tight spacing |
| sm | 8px | Compact element spacing, input padding |
| md | 16px | Default element spacing, section internal padding |
| lg | 24px | Section padding, card spacing |
| xl | 32px | Layout gaps, major element spacing |
| 2xl | 48px | Major section breaks, hero padding |
| 3xl | 64px | Page-level vertical rhythm, section separation |

Exceptions: Touch targets (buttons, form inputs) minimum 44px (mobile accessibility requirement). Hero section may use larger values for visual impact (96px, 128px) within grid-based design.

**Source:** Standard 8-point scale (no upstream override), Emerald Intelligence design philosophy emphasizes spacious, premium layouts.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (Regular) | 1.5 | Paragraph text, service descriptions |
| Label | 14px | 500 (Medium) | 1.4 | Form labels, small UI text |
| Heading H2 | 20px | 600 (Semibold) | 1.2 | Section headings (Servicios, Nosotros, Equipo) |
| Heading H1 | 28px | 600 (Semibold) | 1.2 | Hero headline, page title |
| Display | 36px | 700 (Bold) | 1.1 | Rare; hero main statement (optional, use 28px H1 default) |

Font family:
- **Sans-serif (default):** Inter (UI, body, headings)
- **Monospace (technical):** Roboto Mono (code snippets, feature lists with monospace accents)

Loading strategy: Both fonts loaded via `next/font/google` with `display: 'swap'` to prevent FOUT (Flash of Unstyled Text).

**Source:** Emerald Intelligence philosophy + research recommendation for B2B consulting (conservative, professional). PERF-04 requires next/font usage.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #050505 (Void Black) | Page background, main surfaces, dark mode default |
| Secondary (30%) | #0d1117 (Deep Slate) | Cards, section backgrounds, sidebar/nav, subtle contrast |
| Accent (10%) | #10b981 (Emerald Nexus) | Primary CTA buttons, links, focus states, interactive highlights |
| Semantic: Destructive | #ef4444 (red-500) | Delete actions, error states, warnings only |

**Accent reserved for:**
- Primary CTA buttons ("Agendar consultoría", "Enviar mensaje")
- Link hover states
- Focus rings (keyboard navigation)
- Interactive state indicators (toggle on, form validation success)
- Icon highlights in feature lists
- Emerald glow/accent particles in hero (if animated)

**Never use accent for:**
- Body text
- Background colors (bleeds brand; use as accent only)
- All interactive elements (reserve for primary actions)

Shadows and borders: Use Deep Slate (#0d1117) for subtle shadows and borders. Leverage CSS variable system from shadcn preset: `var(--primary)`, `var(--secondary)`, `var(--accent)`, `var(--background)`.

**Color tokens (CSS variables mapped to Tailwind):**
- `--primary`: #10b981 (Emerald Nexus)
- `--secondary`: #0d1117 (Deep Slate)
- `--background`: #050505 (Void Black)
- `--foreground`: #ffffff (white text on dark)
- `--card`: #0d1117 (Deep Slate)
- `--card-foreground`: #ffffff
- `--accent`: #10b981 (Emerald Nexus)
- `--accent-foreground`: #ffffff

**Source:** CONTEXT.md locked brand colors + Emerald Intelligence philosophy + master brand kit (master_brand_kit.md specifies exact hex values).

## Component Inventory

### Section Components (Server Components — no 'use client')

Generated via Stitch MCP with Emerald Intelligence design:

| Component | Purpose | Stitch Output |
|-----------|---------|---------------|
| **Hero** | Hero section with headline, subheading, stats, CTA button, optional animated background | TypeScript + Tailwind CSS, responsive layout |
| **Servicios** | 6 service cards (grid layout, 2-3 column responsive) with icon, title, description, feature list | TypeScript + Tailwind CSS, card-based |
| **Nosotros** | About section: company value prop, team intro, mission statement | TypeScript + Tailwind CSS |
| **Equipo** | Team member cards (3-4 displayed, with photo, name, role, bio) | TypeScript + Tailwind CSS |
| **Contacto** | Contact section: email, phone, social links, embedded contact form | TypeScript + Tailwind CSS |
| **Footer** | Footer with copyright, links, social icons, company info | TypeScript + Tailwind CSS |

All Stitch outputs must:
- Use Tailwind utility classes (no CSS-in-JS or scoped styles)
- Follow Emerald Intelligence philosophy (void black bg, emerald accents, premium spacing)
- Support dark mode via Tailwind dark: class (not required for Phase 1, but prepare structure)
- Be fully typed TypeScript (no `any` types)
- Export as default React component
- Use `cn()` utility from lib/utils.ts for className merging (shadcn pattern)

### Interactive Components (Client Components — 'use client' only where needed)

| Component | Type | 'use client' | Purpose |
|-----------|------|-------------|---------|
| **Navigation** | Client | Yes | Sticky/fixed nav with scroll state, anchor links |
| **ScheduleModal** | Client | Yes | Modal form for scheduling; migrated from React SPA |
| **ChatWidgetLoader** | Server Wrapper | No | Dynamic import wrapper, lazy-loads chat |
| **@n8n/chat** | Client | (via dynamic import) | Chat widget (Phase 4 — not implemented in Phase 1) |

Navigation must:
- Track scroll position to highlight active section
- Support anchor links (#hero, #servicios, #nosotros, #equipo, #contacto)
- Be sticky/fixed (typical B2B pattern)
- Show Emerald Nexus (#10b981) highlight on active section

ScheduleModal must:
- Accept form inputs: name, email, phone, date, time
- Validate client-side (basic) + server-side (Phase 3)
- Submit to `/api/webhook/n8n/schedule` (Phase 3)
- Show loading/success/error states with copy from Copywriting Contract

## Image Optimization

**All images** must use `next/image` (PERF-03 requirement):
- Automatic WebP/AVIF optimization
- Lazy loading (except above-the-fold hero)
- Declared dimensions (prevents layout shift)
- srcSet for responsive sizes

Hero image (LCP critical):
- Preload: `priority={true}`
- Format: WebP preferred, JPG fallback
- Dimensions: 1920x1080 or 1200x600 (declare aspect ratio)

Content images (lazy):
- `loading="lazy"`
- Dimensions declared
- srcSet: 1x, 2x at minimum

Service icons:
- Lucide SVG icons (via lucide-react package) preferred over images
- If custom icons needed: SVG files loaded inline

## Accessibility (WCAG 2.1 AA minimum)

- [ ] Color contrast: text ≥ 4.5:1 (normal), ≥ 3:1 (large)
- [ ] Focus visible: ≥ 3px outline on interactive elements (native browser or Tailwind `focus:ring`)
- [ ] Keyboard navigation: all interactive elements reachable via Tab
- [ ] Alt text: every image has descriptive alt (lucide icons do not need alt)
- [ ] Form labels: associated with inputs via `htmlFor`
- [ ] Semantic HTML: use `<button>` for buttons, `<a>` for links (not `<div>`)
- [ ] Aria labels: landmarks (`<nav>`, `<main>`, `<footer>`) don't need aria-label if semantic

## Visual Hierarchy

1. **Page Background:** Void Black (#050505) — dominates 60%
2. **Surfaces/Cards:** Deep Slate (#0d1117) — 30% secondary
